# Gran Turismo 2 Combined — NTSC-U 1.2 base

Experimental clean Linux baseline for a Combined Disc whose boot executable
is derived from the NTSC-U 1.2 Simulation program.

The existing GT2 enhancement sources in this repository are validated against
NTSC-U 1.1 and are intentionally not linked into this profile.

Initial milestones:

1. native Linux compilation
2. BIOS boot
3. game boot
4. menu
5. first race

Revision-specific enhancements are rebased only after the vanilla baseline is
validated.

User-owned BIN/CUE files are immutable inputs.
